# Results

- `screening/`: regenerated hard-gate, P1-P3 and P4 tables.
- `final_candidates/final_12.csv`: final synthesis manifest with priority labels.
- `final_candidates/structures/`: Boltz-2 model-0 predicted complexes used in
  manual structural review.
- `structures/`: 1,990 BoltzGen design and 7,960 BoltzIF redesign CIF/NPZ
  pairs, with SHA-256 checksums.
- `manuscript_predictions/`: target-context Boltz-2 follow-up structures and
  per-model confidence/affinity scores, kept separate from the main ranking.
- `submission/results.csv`: authoritative UTF-8 competition candidate manifest
  generated by `bash targets/hiapp/run.sh`.
- `submission/README.md`: column definitions and interpretation guide.
- `submission/run_metadata.json`: runtime, repository revision, and checksums
  generated on each evaluator run. This machine-specific file is intentionally
  untracked.

All entries are computational predictions. Activity fields are marked
`not_measured`; assay measurements and laboratory records are outside this
release.
