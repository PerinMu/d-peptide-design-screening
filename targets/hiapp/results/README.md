# Results

- `screening/`: regenerated hard-gate, P1-P3 and P4 tables.
- `final_candidates/final_12.csv`: historical selection table with priority
  labels and legacy status fields.
- `final_candidates/structures/`: Boltz-2 model-0 predicted complexes used in
  manual structural review.
- `structures/`: 1,990 BoltzGen design and 7,960 BoltzIF redesign CIF/NPZ
  pairs, with SHA-256 checksums.
- `manuscript_predictions/`: target-context Boltz-2 follow-up structures and
  per-model confidence/affinity scores, kept separate from the main ranking.
- `submission/results.csv`: authoritative UTF-8 computational candidate
  manifest generated by `bash targets/hiapp/run.sh`; the inherited directory
  name is retained for compatibility.
- `submission/README.md`: column definitions and interpretation guide.
- `submission/run_metadata.json`: runtime, repository revision, and checksums
  generated on each reproduction run. This machine-specific file is intentionally
  untracked.

The released scores and structures are computational outputs. The legacy
status fields in `final_12.csv` are not current experimental-status claims;
the computational release contains no assay outcomes or laboratory records.

The [recovered screening files](recovered_screening/README.md) include the
model-0 structure index, preserved score exports and portable prediction YAMLs.
