# Tau final computational candidate roster

[`final_10.csv`](final_10.csv) transcribes the ten sequences and thirteen
prediction metrics from Supplementary Table 1 in table order. Names are
capitalized consistently. The TAU-DP identifiers identify rows of this release
and do not indicate screening rank. Score cells preserve the supplementary
values, including the EG-9 confidence discrepancy.

[`score_alternatives.csv`](score_alternatives.csv) lists every same-sequence
record in the merged screening table, with the original metrics, source ID
and model-0 structure. A structure in this table corresponds to that scoring
record. Its presence alone does not establish which model was used for the
supplement. In a CIF location, `archive.tar.gz::member.cif` identifies an
archive member. See the [recovery audit](../../../../docs/COMPUTATIONAL_DATA_RECOVERY.md)
for matching rules and remaining discrepancies.
