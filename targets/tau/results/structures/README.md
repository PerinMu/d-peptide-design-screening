# Tau structure archives

These compressed archives contain only the locally retained structure outputs
for the main Tau BG_10000 campaign:

- `boltzgen_bg10000_design_cifs.tar.gz`: 9,990 BoltzGen design CIF files.
- `boltz2_bg10000_model0_cifs.tar.gz`: 8,927 Boltz-2 model-0 CIF files.

The original file basenames are preserved. Extract each archive into a
separate directory. Checksums are recorded in `SHA256SUMS.txt`.
